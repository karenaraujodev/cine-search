SOBRE O PROJETO

Conheça o Cine Search.

Um projeto desenvolvido para praticar programação, explorar novas tecnologias e tornar a busca por filmes mais simples e agradável.

O que é o Cine Search?

O Cine Search é uma aplicação web para busca de filmes. Através dela, é possível pesquisar títulos, visualizar informações sobre os filmes e salvar seus favoritos.

Tecnologias utilizadas

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript. Também foram utilizados conceitos como consumo de API, requisições assíncronas, manipulação do DOM e armazenamento de dados no Local Storage.

Como funciona?

O usuário pesquisa pelo nome de um filme e o Cine Search realiza uma consulta à API do TMDB para encontrar os resultados. As informações encontradas são exibidas na página em forma de cards.

Favoritos

Os filmes podem ser adicionados aos favoritos e ficam armazenados no navegador através do Local Storage. Dessa forma, é possível acessar os filmes salvos posteriormente.

O que estou praticando?

Este projeto faz parte do meu processo de aprendizagem em desenvolvimento web. Durante sua construção, estou praticando JavaScript, consumo de APIs, manipulação do DOM, eventos, arrays, objetos, funções e armazenamento de dados.
